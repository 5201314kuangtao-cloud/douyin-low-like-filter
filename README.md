# 抖音低赞过滤 / 筛选高赞视频

刷抖音自动跳过低赞视频，只给你看好内容。

点赞不够的视频自动划走，女生、直播、音乐类内容自动保留，不踩雷、不浪费时间。所有设置本地保存，刷新不丢失。

## 功能

- 自动跳过低赞视频，只保留高赞内容
- 点赞阈值自由调节（1万 ~ 100万，9档可选）
- 女生相关视频自动保留，不跳过
- 直播、音乐内容自动保留
- 左上角悬浮图标一键打开控制面板
- 四个开关自由切换：颜值保留 / 自动清屏 / 音乐保留 / 保留直播
- 菜单大小和位置自动记忆，下次打开恢复原样

## 安装

1. 点右上角绿色 **Code** 按钮，选 **Download ZIP** 下载
2. 解压压缩包到一个文件夹
3. 打开 Chrome，点右上角三个点选择扩展。又或者地址栏输入 `chrome://extensions` 回车
4. 右上角打开 **开发者模式**
5. 把解压好的文件夹直接拖到页面里
6. 打开抖音 `https://www.douyin.com`，左上角出现悬浮图标就装好了

## 面板说明

| 按钮 | 作用 |
|------|------|
| 1万~100万 | 设置点赞阈值，低于这个数的视频自动跳过 |
| 颜值保留 | 开启后，含女生关键词的视频不跳过 |
| 自动清屏 | 开启后，自动跳过广告和游戏推广视频 |
| 音乐保留 | 开启后，汽水音乐相关视频不跳过 |
| 保留直播 | 开启后，直播间不跳过 |
| 清除程序 | 重置所有设置和记忆 |

## 注意事项

- 本扩展只在抖音网页版生效，抖音客户端不支持
- 推荐使用 Chrome 浏览器，抖音网页版在 Chrome 上可选 4K 画质，其他浏览器最高仅 1080p
- 首次使用建议先选 2万 阈值，觉得刷到的视频质量不够再调高
- 如果悬浮图标没出现，刷新一下抖音页面即可
- 扩展更新后，需要在 `chrome://extensions` 页面点扩展卡片上的刷新按钮
- 面板可拖动到屏幕任意位置，大小和位置自动记忆，刷新不丢失
- 快捷键：W 或 ↑ 回看上个视频，S 或 ↓ 继续刷，空格暂停自动跳过
- 跳过太快就调高点赞阈值，跳得太慢就调低，建议从 2万 开始试
- 抖音页面大版本更新后可能短暂失效，刷新页面或等扩展更新即可
- 本扩展完全本地运行，不收集、不上传任何个人数据
