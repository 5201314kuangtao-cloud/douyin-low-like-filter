# 抖音低赞过滤 / 筛选高赞视频

刷抖音自动跳过低赞视频，只给你看好内容。

点赞不够的视频自动划走，女生、直播、音乐类内容自动保留，不踩雷、不浪费时间。所有设置本地保存，刷新不丢失。

## 功能

- 自动跳过低赞视频，只保留高赞内容
- 点赞阈值自由调节（1万 ~ 100万，9档可选）
- 女生相关视频自动保留，不跳过
- 直播、音乐内容自动保留
- 左上角悬浮图标一键打开控制面板
- 四个开关自由切换：颜值保留 / 自动清屏 / 音乐保留 / 保留直播
- 菜单大小和位置自动记忆，下次打开恢复原样

### 方式二：手动安装

#### 第一步：下载

1. 点本页面右上角绿色的 **Code** 按钮
2. 点最下面的 **Download ZIP**
3. 下载后得到一个压缩包

#### 第二步：解压

1. 右键点压缩包，选 **解压到当前文件夹**
2. 打开解压后的文件夹，确认里面有 `content.js`、`manifest.json`、`icon48.png`、`icon128.png` 这四个文件

#### 第三步：安装到 Chrome

1. 打开 Chrome 浏览器
2. 地址栏输入 `chrome://extensions` 按回车
3. 右上角打开 **开发者模式**（开关变蓝就是开了）
4. 把刚才解压好的文件夹，**直接拖到这个页面里**
5. 看到扩展卡片出现，就是安装成功了

#### 第四步：使用

1. 打开抖音网页版 `https://www.douyin.com`
2. 左上角会出现一个红色悬浮图标
3. 点一下图标，打开控制面板
4. 选择你想要的点赞阈值（默认2万）
5. 打开或关闭 颜值保留 / 自动清屏 / 音乐保留 / 保留直播
6. 开始刷抖音，低赞视频会自动跳过

## 面板说明

| 按钮 | 作用 |
|------|------|
| 1万~100万 | 设置点赞阈值，低于这个数的视频自动跳过 |
| 颜值保留 | 开启后，含女生关键词的视频不跳过 |
| 自动清屏 | 开启后，自动跳过广告和游戏推广视频 |
| 音乐保留 | 开启后，汽水音乐相关视频不跳过 |
| 保留直播 | 开启后，直播间不跳过 |
| 清除程序 | 重置所有设置和记忆 |

## 注意事项

- 本扩展只在抖音网页版生效，抖音客户端不支持
- 首次使用建议先选 2万 阈值，觉得刷到的视频质量不够再调高
- 如果悬浮图标没出现，刷新一下抖音页面即可
- 扩展更新后，需要在 `chrome://extensions` 页面点扩展卡片上的刷新按钮
